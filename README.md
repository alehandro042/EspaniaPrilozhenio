# Еспаньола

PWA для изучения испанского по учебнику «Español Actual. Современный испанский язык. Начальный курс» (Гринина Е.А., Микаэлян Ю.И., МГИМО). Интерфейс на русском, рассчитано на телефон (Android, Chrome), работает офлайн и ставится на главный экран.

## Что внутри
- Уроки по оглавлению: Словарь (глаголы / остальные слова / фразы…), Грамматика, Построение предложений.
- Карточки с интервальным повторением, ошибочные слова повторяются чаще.
- Тесты: выбор перевода, на слух, картинки, написание, спряжение и артикли из таблиц учебника, сборка предложений.
- У каждого урока свой уровень (лёгкий → средний → сложный): повышается после двух тестов подряд на 80%+, не понижается.
- Озвучка испанским голосом и приблизительная проверка произношения (Web Speech API).
- Свои слова: вручную, списком «слово — перевод», по фото (через Gemini).
- ИИ-помощник: выбор сервиса (Gemini, Groq, OpenRouter, Mistral — бесплатно; DeepSeek, OpenAI, Claude — платно), свой ключ хранится только на устройстве; без ключа — кнопка «Спросить Gemini».
- Синхронизация через Google Диск (скрытая папка приложения). Настройка: [SETUP-GOOGLE.md](SETUP-GOOGLE.md).

## Данные учебника
Всё учебное содержимое берётся только из `textbook/` (формат описан в SCHEMA.md в общей папке проекта):
- `textbook/contents.json` — оглавление; урок появляется в приложении, когда у него есть поле `"file"`.
- `textbook/lessons/uU-lL.json` — уроки.
- `textbook/images/index.json` — необязательные картинки к словам: `{"words": {"<es>": {"file": "images/…", "author": "…", "license": "…", "source": "…"}}}`.

Новый урок = новый JSON + поле `file` в оглавлении. Код менять не нужно. Обновить из общей папки: `sh tools/sync-textbook.sh`.

## Устройство
Без сборки: чистые ES-модули (`js/`), `sw.js` — офлайн-кэш (оболочка — из кэша, учебник — сначала сеть), `config.js` — OAuth Client ID и модель Gemini.
