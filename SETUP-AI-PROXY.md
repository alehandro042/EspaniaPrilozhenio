# DeepSeek для всех без ключа (Cloudflare Worker)

Ключ GPTunnel нельзя класть в код сайта: код сайта виден любому, и ключ украдут.
Поэтому между приложением и GPTunnel стоит маленький бесплатный посредник на Cloudflare.
Ключ хранится в секрете посредника, приложение его не видит.

Посредник пропускает только запросы с сайта https://alehandro042.github.io,
всегда использует одну модель (deepseek-v4-pro), ограничивает длину запроса и ответа.

## 1. Новый ключ GPTunnel
1. gptunnel.ru → Профиль → вкладка «API».
2. Удалите старый ключ (если он где-то засвечен) и создайте новый.
3. В списке разрешённых моделей ключа оставьте только DeepSeek V4 Pro.

## 2. Аккаунт Cloudflare
1. Откройте https://dash.cloudflare.com/sign-up, введите почту и пароль, подтвердите почту.
2. Домен и карта не нужны. Бесплатно: 100 000 запросов в день.

## 3. Создать Worker
1. В меню слева: **Compute (Workers) → Workers & Pages** → кнопка **Create**.
2. Выберите **Start with Hello World!**, имя: `espanola-ai` → **Deploy**.
3. Нажмите **Edit code**. Удалите весь код в редакторе и вставьте код из файла
   https://github.com/alehandro042/EspaniaPrilozhenio/blob/main/worker/ai-proxy.js
   (на GitHub кнопка «Copy raw file» справа над кодом).
4. Нажмите **Deploy** (справа вверху).

## 4. Положить ключ в секрет
1. Вернитесь на страницу Worker → вкладка **Settings** → **Variables and Secrets** → **Add**.
2. Type: **Secret**, Variable name: `GPTUNNEL_KEY`, Value: ваш новый ключ GPTunnel.
3. **Deploy** (или **Save**).
4. Если модель в GPTunnel называется иначе, добавьте так же переменную `MODEL` (тип Text) с точным названием.

## 5. Адрес
На странице Worker есть адрес вида `https://espanola-ai.ВАШЕ-ИМЯ.workers.dev`.
Пришлите его (это не секрет), он вписывается в `config.js` → `aiProxyUrl`.
После этого у всех пользователей в Помощнике сразу работает «DeepSeek от приложения».

## Безопасность
- Проверка сайта защищает от чужих сайтов, но не от человека, который нарочно пишет скрипт.
  Поэтому главная защита — баланс: держите на GPTunnel небольшую сумму и пополняйте понемногу.
- Расходы видны в GPTunnel (история списаний).
- Если кто-то начал тратить слишком много: удалите ключ в GPTunnel или нажмите в Worker
  **Settings → Disable** — приложение продолжит работать, просто ИИ без ключа отключится.
